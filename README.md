# MoneyMood · 情绪记账本

> 把情绪变成预算的一部分，让每一分钱都服务于你的生活。

MoneyMood 是一款专注于「情绪 → 消费」关系的小而美记账 App。核心理念：**不是控制你花钱，而是让你看见钱花在哪里、为什么花。**

## 核心概念

### 三个资金池

每笔消费自动归入三个「池子」，代表三种不同的消费动机：

| 池子 | 图标 | 含义 | 典型消费 |
|------|------|------|----------|
| **刚需基础池** | 🌱 | 维持基本生活的必要支出 | 餐饮、交通、房租、学习 |
| **悦己享受池** | 💗 | 主动犒劳自己的快乐支出 | 娱乐、兴趣、社交、礼物 |
| **压力缓冲池** | ☁️ | 应对情绪波动/压力时的弹性支出 | 外卖、临时购物 |

### 先存后花

每月收入先按比例「先存起来」，剩余部分再分配到三池。这样存钱是自动的、可视化的，而不是月末剩多少存多少。

## 功能一览

### 首页 · 今日消费流

- 展示今日消费列表，每笔记录显示：金额、类别、时间、情绪标签
- 点击任意一笔可编辑/删除
- 按三池分别统计今日已花 / 当天预算

### 记账页 · 快速记一笔

- 输入金额 → 选择池子 → 打上情绪标签 → 可选附注
- 支持语音输入（未来扩展）
- 情绪标签：😊开心 🙂平静 😐一般 😣压力 😞低落 😪疲惫

### 预算页 · 三轨预算

三个 tab 切换：**本周 / 本月 / 本年**

#### 本周预算（增强版）

- 显示本周三个池子的已花、额度、剩余
- **本周额度可直接修改**（点击数字即可编辑），修改结果会同步到月内周计划
- **每日还能花实时计算**：`剩余金额 / 本周剩余天数 = 每日还能花 ¥X`
- **超支警告**：若某个池子超支，进度条显示警告色（红色），顶部显示推荐调整建议
- 调剂建议：根据各池消耗速度，自动提示「从宽裕池调额度给紧张池」
- 进度条 + 每日可花金额提示

#### 本月预算（重点更新）

- **月内节奏**：时间进度 vs 花钱进度对比，超前/落后一目了然
- **月内周计划日历**（增强版）：
  - 横向滚动的 4~6 张周卡，每张卡显示：
    - 第 N 周 + 起止日期范围
    - 当前周有粉红「本周」徽标 + 高亮边框
    - 三池已花/总额 mini 进度条
  - 右上角 ✎ 按钮打开编辑弹窗，可单独调整该周三池额度
  - **📐 自动分配**：把月池总额按天数占比分配到各周
  - **⚡ 按当前节奏重排**：根据已有消费数据推算各周应分配额度
- **三池结余预测**：月底预计超支/正常/宽裕，提前预警
- **存钱罐**：旅行基金、备用金等目标存钱罐，支持存入/取出
- **月结自动转入**：开关控制月底三池结余是否自动转入存钱罐
- **情绪攒钱玩法**：开心圆零存、忍住奖励存、零缓冲打卡存

#### 本年预算

- 年度存钱目标进度
- 12 个月花钱/存钱双曲线柱状图（点击可看当月三池分布）
- 策略档位：保守攒钱 / 平衡生活 / 尽情体验
- 全年悦己/缓冲占比上限监控

### 复盘页 · 情绪洞察

- 本月情绪分布（饼图）
- 情绪 → 消费额排行榜：哪种情绪下花得最多
- 小M洞察 + 行动建议

## 三轨预算系统

### 数据流向（本年 → 本月 → 本周）

```
┌─────────────────────────────────────────────────────────────────┐
│                         本年策略                                 │
│  月薪 ¥8000 × 策略档位(保守20%/平衡17%/尽情15%)               │
│                         ↓                                       │
│              年度目标 = 月薪 × 存钱率 × 12                      │
└─────────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────────┐
│                         本月分配                                 │
│  预存额度 = 月薪 × 存钱率                                       │
│  可花总额 = 月薪 - 预存额度                                     │
│  三池分配 = 可花总额 × 三池百分比（按策略档位）                  │
│                         ↓                                       │
│         月内周计划（4~6周）按天数比例分配                        │
└─────────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────────┐
│                         本周执行                                 │
│  本周预算 = 月内周计划中「包含今天」的那一周                      │
│  每日还能花 = (本周预算 - 本周已花) / 本周剩余天数               │
│  超支警告 = 检测到超支时显示警告和建议                           │
└─────────────────────────────────────────────────────────────────┘
```

### 关键规则

- **改本年策略**：自动联动更新本月三池分配和周计划额度
- **改月池总额**：所有周的该池按当前比例同比例缩放
- **改单周额度**：直接更新那一周，并重新汇总到月池总额
- **本周额度**：由月内周计划的「包含今天的那一周」决定
- **切换月份**：自动重新生成周计划，旧数据保留到对应周

## 情绪记账

每笔消费记录可以打上情绪标签：

| 情绪 | 含义 | 建议 |
|------|------|------|
| 😊 开心 | 正向激励消费 | 正常享受 |
| 🙂 平静 | 日常必要消费 | 属于刚需池 |
| 😐 一般 | 常规消费 | 正常记录 |
| 😣 压力 | 压力释放消费 | 建议冷静 10 分钟 |
| 😞 低落 | 情绪低落消费 | 先抱抱自己 |
| 😪 疲惫 | 疲劳补偿消费 | 休息比消费更补 |

情绪数据用于：
- 复盘页的情绪分布图
- 消费洞察：哪种情绪下花得最多
- 预算建议：根据情绪调整各池额度

## 数据存储

所有数据存储在浏览器 `localStorage` 中：

| Key | 内容 |
|-----|------|
| `moneymood-records-v1` | 消费记录列表 |
| `moneymood-month-budget-v1` | 月预算 + **周计划** |
| `moneymood-savings-goals-v1` | 存钱罐目标 |
| `moneymood-year-goal-v1` | 年度目标 |
| `moneymood-settlement-v1` | 月度结算结果 |

> 注意：清除浏览器数据会导致所有记录和预算丢失，建议定期导出（未来功能）。

## 开发指南

### 技术栈

- **框架**：React 19 + TypeScript
- **构建**：Vite 7
- **样式**：Tailwind CSS v4（CSS-first 配置）
- **状态**：React `useState` / `useCallback`（无外部状态管理库）
- **持久化**：localStorage

### 核心类型定义（types.ts）

```typescript
// 三池预算详情
type PoolBudgetDetail = {
  id: PoolId;
  total: number;        // 预算总额
  used: number;         // 已花费
  remaining: number;     // 剩余可用
  percent: number;      // 使用百分比
  forecastRate: number; // 预测月底使用率
  dailyQuota: number;   // 每日还能花
  restDays: number;     // 本周剩余天数
  status: BudgetStatus; // 正常/偏快/危险
};

// 周计划
type WeekPlan = {
  weekIdx: number;      // 周序号
  startDate: string;    // 开始日期
  endDate: string;      // 结束日期
  totals: PoolTotals;   // 三池额度
};

// 月度结算
type MonthlySettlement = {
  income: number;       // 收入
  saveAmount: number;   // 预存金额
  spendable: number;    // 可花总额
  actualSpend: PoolTotals;    // 实际花费
  surpluses: PoolTotals;      // 各池结余
  transfers: PiggyTransfer[]; // 存钱罐转入
  totalSaved: number;   // 本月总存
};

// 超支警告
type OverspendAlert = {
  poolId: PoolId;
  overAmount: number;
  suggestion: string;
  suggestedTransfer: number;
  transferFromPool?: PoolId;
};
```

### 关键计算函数（insight.ts）

```typescript
// 计算本周预算详情

detectOverspendAndSuggest(pools, budgets)

```
